- Initial release for Minecraft 1.21.11
- Hostile mobs drop about 1.35× more XP from combat (bosses unchanged)
- Rare elite overworld hostiles spawn naturally — tougher, slightly larger, with red dust particles
- Player-killed elites grant bonus XP, a short amethyst chime, and one extra vanilla loot roll
- Elite enchanted books use kill-method routing (melee, ranged, or fallback pools)
- Server config at `config/mob_combat_rebalance.json` with independent pillar toggles
